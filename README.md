# SOHTMON

Сайт-программа для заказа бетономешалок.

- Каталог товаров (список `PRODUCTS` в `app.js` — добавьте объект, чтобы добавить товар)
- Форма заказа: количество, самовывоз/доставка, имя, телефон, комментарий
- Автоподсчёт суммы
- Отправка заказа в WhatsApp на номер магазина и кнопка звонка
- История заказов в браузере

Запуск: откройте `index.html` в браузере (или включите GitHub Pages).

## ERP-система (`erp.html`)

Учёт для магазина: откройте `erp.html` (ссылка «Вход для персонала» внизу сайта).

- **Главная** — выручка и чистая прибыль за месяц, долги клиентов, стоимость склада, заказы в работе, товары с низким остатком
- **Продажи** — документы с несколькими товарами, скидкой, доставкой, статусами (новый → подтверждён → отгружен → выполнен / отменён), частичной оплатой, печатью накладной, экспортом в CSV (Excel)
- **Склад** — товары, себестоимость, цена, наценка, остатки (считаются автоматически: начальный остаток + закупки − продажи), сигнал о минимальном остатке
- **Закупки** — приход товара от поставщиков, долг перед поставщиком; себестоимость товара обновляется по последней закупке
- **Клиенты / Поставщики** — контакты, оборот, долги
- **Расходы** — по категориям (аренда, зарплата, транспорт…)
- **Отчёты** — за любой период: выручка, себестоимость, валовая и чистая прибыль, продажи по товарам и месяцам, расходы по категориям, должники
- **Настройки** — данные компании, резервная копия (скачать/загрузить JSON), очистка

Данные хранятся в браузере (localStorage) на этом устройстве. Регулярно скачивайте резервную копию в «Настройках» — с её помощью можно перенести учёт на другой компьютер.
