# SOHTMON

Сайт-программа для заказа бетономешалок.

- Каталог товаров (список `PRODUCTS` в `app.js` — добавьте объект, чтобы добавить товар)
- Форма заказа: количество, самовывоз/доставка, имя, телефон, комментарий
- Автоподсчёт суммы
- Отправка заказа в WhatsApp на номер магазина и кнопка звонка
- История заказов в браузере

Запуск: откройте `index.html` в браузере (или включите GitHub Pages).
